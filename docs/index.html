Backup yang Bikin Tenang

MySQL & PostgreSQL backup automation. Set it once, run it forever.

Get started in three commands:

$ curl -L https://raw.githubusercontent.com/abdullahainun/tenangdb/main/config.yaml.example -o config.yaml
  # edit config.yaml with your database credentials
$ docker run --rm -v $(pwd)/config.yaml:/config.yaml ghcr.io/abdullahainun/tenangdb backup --yes

Capabilities

Interactive setup

Run tenangdb init for a guided wizard. It checks dependencies, tests connections, and generates your config.

Metrics & monitoring

Prometheus endpoint at :9090. Grafana dashboard and 9 alert rules included — know when things go wrong.

Cloud upload

S3, GCS, Azure, and 40+ providers via rclone. Custom flags supported via upload.extra_flags.

Compression

tar.gz, tar.zst, tar.xz. PostgreSQL custom format includes compression by default.

Scheduling

cron or systemd timer. Standard Unix scheduling, no extra infra, no lock-in.

Two engines

MySQL 5.7+ (via mydumper or mysqldump) and PostgreSQL 12+ (via pg_dump). One config, both supported.
