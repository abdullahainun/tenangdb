Quick Start

Get TenangDB running in under a minute with Docker

# 1. Download config template
curl -L https://go.ainun.cloud/tenangdb-config.yaml.example -o config.yaml
# 2. Edit with your database credentials
nano config.yaml
# 3. Create backups directory
mkdir -p backups && sudo chown $(id -u):$(id -g) backups
# 4. Run backup
docker run --user $(id -u):$(id -g) \
-v $(pwd)/config.yaml:/config.yaml \
-v $(pwd)/backups:/backups \
ghcr.io/abdullahainun/tenangdb:latest backup --yes
