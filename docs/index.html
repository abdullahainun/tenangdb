Capabilities

01

Interactive setup

Run docker compose run --rm tenangdb init to configure everything interactively. No YAML guessing.

02

Metrics & monitoring

Prometheus endpoint at :9090. Grafana dashboard and 9 alert rules included out of the box.

03

Cloud upload

S3, GCS, Azure, and 40+ providers via rclone. Custom flags supported via upload.extra_flags.

04

Compression

tar.gz, tar.zst, tar.xz. PostgreSQL custom format includes compression by default.

05

Scheduling

cron or systemd timer. Standard Unix scheduling, no extra infra needed.
