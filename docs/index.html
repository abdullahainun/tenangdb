Capabilities

Interactive Setup

docker compose run --rm tenangdb init walks you through the config. No YAML guessing.

Metrics & Monitoring

Prometheus endpoint at :9090. Grafana dashboard and 9 alert rules included.

Cloud Upload

S3, GCS, Azure, and 40+ providers via rclone. Custom flags supported.

Compression

tar.gz, tar.zst, tar.xz. PostgreSQL custom format includes compression.

Scheduling

cron or systemd timer. Simple, reliable, no extra infra.
